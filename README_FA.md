# Ravan — نسخهٔ شخصی تونل

Based on BackPack by Amin Mohammadi (AminMGMT)
https://github.com/AminMGMT/BackPack

این فورک مستقل با مجوز AGPL-3.0 روی نسخهٔ منتشرشدهٔ۱٫۸٫۵ ساخته شده است؛ نسخهٔ
رسمی BackPack نیست. تمرکز روی بازیابی WSS Mux و جلوگیری از گیرکردن نشست‌هایی
است که اپراتور را مجبور به ریستارت ایران می‌کنند. علت انحصاری قطعی روی سرور
واقعی شما بدون گزارش همان زمان اثبات نمی‌شود؛ پایداری چندساعتهٔ مسیر واقعی
همچنان نیاز به آزمون دارد.

## نصب

روی هر دو سرور با root:

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/sabialballa/Ravan/main/install.sh)
```

منوی انگلیسی با `sudo ravan` باز می‌شود. روی ایران **Setup Iran → Reverse → WebSocket → WSS Mux**
را انتخاب کنید، لینک اتصال را بگیرید و در **Setup Kharej → Reverse → WebSocket → WSS Mux → Setup Link**
سرور خارج وارد کنید. برای این مسیر SSH بین دو سرور و ویرایش دستی تنظیمات لازم نیست.
لینک اتصال حاوی اطلاعات دسترسی است؛ آن را عمومی نکنید.

فایل‌ها در `/etc/ravan`، باینری در `/usr/local/bin/ravan` و سرویس‌ها با پیشوند
`ravan-` هستند؛ نصب قبلی BackPack بازنویسی نمی‌شود. اگر هم‌زمان تست می‌کنید، پورت‌های
آزاد جداگانه انتخاب کنید. خاموش‌کردن یا مهاجرت خودکار تونل موجود انجام نمی‌شود.

تست مداوم و race برای WSSmux پاس شده‌اند، اما اجرای اولیهٔ کل مجموعهٔ آزمون‌ها
بدون خطا نبود. اصلاحات، تکرار آزمون‌ها و محدودیت‌های محیط شبیه‌سازی‌شده در
[گزارش آزمون](docs/ravan-validation.json) ثبت شده‌اند؛ این نسخهٔ اولیه برای تست
شخصی منتشر می‌شود و تأیید پایداری چندساعتهٔ مسیر واقعی نیست.

[راهنمای کامل و محدودیت آزمون‌ها](README.md) و [یادداشت‌های بازیابی](docs/ravan.md).
